No backend required.

The Axzora Super App is a mobile-first dApp for the Happy Paisa (HP) token: mint, burn, transfer and stake straight from a browser wallet, with a voice-controlled avatar, live pricing and a built-in wallet view. Everything runs client-side, so there is nothing to host and no server key to leak.

What the app does

All client-side, in one static page

Mint · burn · transfer

Full HP interface against the deployed contract, with BNB gas handling and a pre-flight simulation so a transaction that would revert is caught before you sign it.

Staking

Stake HP for 6% APR with a 30-day lock. Accrued rewards update live and an early withdrawal is blocked in the UI, not just in the contract.

Live price and portfolio

USD and INR pricing from CoinGecko, Dexscreener and BSCScan. The BSCScan key is read from localStorage — it is no longer committed.

Voice and avatar

20+ voice commands, an animated Mr Happy avatar and speech synthesis. Every browser API is feature-detected, so a WebView without speech falls back to text.

On-device biometrics

Face detection over TFJS with version-agnostic model adapters and a clean fallback when a model cannot load. Frames never leave the device.

Built-in wallet

Non-custodial local wallet plus a security manager that watches account and network changes and warns before an unsafe approval.

The rest of the ecosystem

Six repositories, one update channel

AxzoraOS Android

The shell: gesture HUD, hub panel and in-app OTA. Signed v18.18 (versionCode 210), delivered by its own manifest instead of a store.

Axzora Server Node

Local-first OTA hub: /update/check, APK download, families and ledger. Prefers a phone-local APK and only redirects to GitHub when it is missing.

Axzora Ludo WebSocket

Authoritative multiplayer Ludo with AI seat hand-off, a browser client and 17 tests covering the board, captures and a full four-player game to a winner.

Axzora Docs Pages

Install steps, the OTA manifest contract, keyboard and gestures, troubleshooting and a version table.

Run it yourself

Static files, one command

Serve the app locally

git clone https://github.com/axzoraharry/axzora-super-app
cd axzora-super-app
npm start          # http://localhost:5173

Then connect a wallet on BSC mainnet. npm run check runs a syntax and secret scan over the whole tree.

Install AxzoraOS

sha256sum AxzoraOS-18.18.apk
# 1d0ae458d93dfdd04938b11d…
# cert F9276561…90456  (v2 + v3)

Allow installs from the browser, then accept the in-app update dialog.
